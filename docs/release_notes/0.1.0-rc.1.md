> [!TIP]
> macOS 安装包未签名，若提示应用已损坏，执行 `xattr -cr /Applications/UniRhy.app` 移除隔离属性即可

## feat
* 私有化部署，无外部服务依赖
* 跨平台客户端：Web、macOS、Windows、Android、iOS，
* 同账号多设备播放同步，播放进度与队列跨会话持久化
* 插件扩展体系：统一的权限管控与 Host API，支持媒体导入、任务定义与配置持久化
* 曲库管理：扫描、整理、转码，支持文件系统与对象存储
* 官网双语首页与文档中心
